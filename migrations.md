Как изменить структуру таблиц(ы) базы данных

Библиотека sqlalchemy не позволяет вносить изменения в таблицы, если они уже созданы. Но часто случается ситуация, когда после запуска первой версии, появляется необходимость вносить изменения в структуру таблиц(ы).
Управление изменениями (миграции)

Для управления структурой таблиц(ы) базы данных рекомендуется использовать инструмент Alembic:

    Установка:

pip install alembic

    Инициализация (в терминале):

alembic init alembic

Эта команда создаст в проекте директорию с именем alembic. В ней, помимо всего прочего, создастся файл alembic.ini. В alembic.ini в строке с параметром sqlalchemy.url нужно указать путь к базе данных:

sqlalchemy.url = sqlite:///db/news.sqlite?check_same_thread=False

    В директории с именем alembic также будет файл env.py. В нём нужно найти строчку с переменной target_metadata. Там нужно прописать информацию о нашим моделях (data/users и data/news):

import sys
sys.path.insert(0, 'Путь к папке проекта')
from data.db_session import SqlAlchemyBase
import data.__all_models
target_metadata = SqlAlchemyBase.metadata

    В модель users (например, перед create_data) добавляем уровень прав (level) пользователя (простой user(1) или admin(2)):

level = sqlalchemy.Column(sqlalchemy.Integer, default=1)

    Переходим в Терминал и выполняем команду

alembic revision --autogenerate -m "добавили уровень пользователя"

Alembic проанализирует модели базы и создаст в папке alembic/versions новую миграцию с таким кодом:

from alembic import op
import sqlalchemy as sa


# revision identifiers, used by Alembic.
revision = 'revision_number'
down_revision = None
branch_labels = None
depends_on = None


def upgrade():
    # ### commands auto generated by Alembic - please adjust! ###
    op.add_column('users', sa.Column('level', sa.Integer())
    # ### end Alembic commands ###


def downgrade():
    # ### commands auto generated by Alembic - please adjust! ###
    op.drop_column('users', 'level')
    # ### end Alembic commands ###

    upgrade выполняет код для изменения состояния базы
    downgrade — для возврата к предыдущему состоянию.

Для обновления структуры таблицы users выполним в консоли команду:

alembic upgrade head

После этого в таблице users появится новой поле level.

Примечание: к сожалению, alembic не универсален. Из-за ограничений СУБД sqlite, команда alembic downgrade head, к сожалению, не удалит ранее добавленную в таблицу колонку.

Не стоить пренебрегать возможностью дописывать в файлы миграции изменения самостоятельно.

Кроме того, существует flask-migrate — обертка для alembic, упрощающая работу именно для flask-приложений.
